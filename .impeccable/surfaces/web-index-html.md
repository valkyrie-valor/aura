# Surface Brief: Aura App & Web Distribution Portal

## Scope and Visitor Mode

- **Primary target:** `web/index.html` (Persuade / Operate bootstrap portal) and `app/src/main/java/com/aura/installer/ui/` (Operate native Android M3 client).
- **Audience & Job:** Self-hosted homelab owner and invited users downloading the Aura Android installer from the web or managing/updating Nexus-hosted APKs (`Aura`, `Flux`, `NetCal`, `Beanfreak`, `FuelSpotter`, `KingInstaller`, `microG`) inside the native Android app.

## Direction contract

THESIS: An architectural package specification ledger and distribution portal centered on the new Prismatic Aura Portal emblem (layered octagonal/diamond aura rings framing a precision download core), refusing generic app-store icon-card templates and plain monogram circles.

OWN-WORLD: Mineral Viridian (`#006B5E` light / `#5CE1CA` dark), Deep Obsidian Teal (`#0A1514`), Warm Alabaster Stone (`#F3F6F5`), Tonal Mint Container (`#C9EFE8` / `#13312D`), and Amber Update Signal (`#D97706`). Typography pairs geometric display headings (`Plus Jakarta Sans` / expressive M3 headlines) with strict tabular numerals (`JetBrains Mono` / monospace badges) for semantic versions (`v1.1.0`) and byte sizes.

STORY: The visitor immediately recognizes Aura as a trustworthy, engineered private package repository, sees the live suite of hosted homelab apps with their semantic versions, and downloads or installs packages with one tap.

FIRST VIEWPORT: On `web/index.html`, an asymmetric two-column specification hero: left column features the new geometric Aura Portal emblem, display title, versioned primary download CTA (`Aura v1.1.0 · APK`), and technical requirements strip; right column displays the interactive Package Registry Ledger previewing the homelab suite (`Flux`, `NetCal`, `Beanfreak`, `Aura`) with version pills and architecture tags. Inside the Android app, a cohesive branded top bar with the Aura Portal mark, summary status pills, and version-badged package cards across Browse, Local, Installed, and Settings.
