Distribution & Device Architecture

Git-Tag Release Bundling
Pushing a semantic Git tag (vX.Y.Z) injects versionName and computed integer versionCode into Gradle, signs the release bundle, replaces stale artifacts in Nexus 3, and publishes <AppName>-v<Version>.apk.
/apks/<slug>/<App>-vX.Y.Z.apk
ChriGa API Version Resolver
NexusService extracts canonical display titles and semantic version badges, deduplicates per repository folder so the highest version wins, and streams binary APK payloads via authenticated X-Api-Key endpoints.
GET /api/apps/{name}/download
Material You Monochrome Icons
Every suite application ships a dedicated vector <monochrome> layer in mipmap-anydpi-v26, allowing Android 13+ launchers to dynamically tint app drawer icons to match the active wallpaper and dark/light theme.
@drawable/ic_launcher_monochrome
Local Storage & Package Manager
Pick standalone APK bundles from device storage with Room-backed history, monitor foreground streaming progress, and inspect or uninstall user-installed packages with full English and German localization.
NavigationSuiteScaffold · Room
